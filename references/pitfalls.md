# 常见坑速查表

按现象查。先做"先查什么"那一列，确认原因后再动手；改之前读一遍对应规则（编号指 `rulebook.md`）。讲解片和广告都适用，只对广告成立的行标了〔广告〕。

## 画面：关键帧与视频生成

| 现象 | 先查什么 | 规则 |
|---|---|---|
| 生成画面一股 CG 味，材质像灰模 | 写实感是否已经在关键帧里、关键帧是否当首帧用；参考视频是不是低采样预览 | 2.1、3.1、2.7 |
| 视频中途硬切到另一个画面 | 参考包里有没有机位不同的图；提示词里有没有"全景、拉远、俯视" | 4.3、4.6 |
| 产品边缘变成灯带、整个产品变成一盏灯，或常亮的灯中途熄灭、变暗 | 提示词里的"发光、光晕、光波"、没注明"不发光"的材质颜色词，以及"最低、变暗、呼吸"这一族词 | 4.4、4.12 |
| 烟、雾、光这类效果从错的地方出来，或者用量过大 | 效果的真实出处、最大范围、肉眼可查的用量标准写了没有；3D 里有没有裁切和封顶 | 4.5、2.9 |
| 画面里凭空多出门、物体或第二个产品 | 提示词是否点名了画面外的东西；关键帧里的产品数量 | 4.6、3.7 |
| 人物动作僵硬、瞬间坐下、身体扭曲 | 预演替身是不是方块四肢；提示词里有没有逐步写身体怎么动 | 2.8 |
| 草稿中段出现重影（两个插头、两只袖子） | 首尾帧之间的内部叠化；按 0.25 秒逐帧看，找干净的区间 | 5.2、6.4 |
| 短镜头的颜色变化中途经过不该有的颜色（比如粉色），或运动中冒出首帧里没有的东西 | 是不是用了首尾帧模式；能不能加一张中间关键帧，改用有序关键帧 | 4.14、1.7 |
| 同一镜头里出现没设计过的推拉 | 这个镜头几张关键帧的缩放是否一致；能不能配准对齐回底图 | 3.7、3.8 |
| 同一件产品或同一个房间在不同关键帧里长得不一样 | 母版是不是先画好、过了检查点，每张都上传了；统一设定是不是逐字相同 | 3.11、3.3 |
| 后补镜头没有底图，画出来比例和光线对不上 | 图1 是不是已批准的关键帧；有没有写"本张例外"改写统一设定第 2 条 | 3.12 |
| 产品上的 logo 或字样变成乱码 | 原片逐帧查字样；能不能换不露字的角度，或在剪辑层贴片 | 5.3、7.1 |
| 平台拒收素材 | 素材里有没有写实人脸；人物图是不是平台认可、未改动的原图 | 3.6 |
| 竖版里产品或字幕被切掉 | 竖版是不是从横版裁出来的；关键帧有没有按竖版单独构图 | 3.10、7.12 |
| 竖版关键帧生成出的草稿是横的，或只剩中间一条 | 提交时的 `--aspect` 和首帧比例是否一致（附带客户端不写时跟随首帧，差 5% 以上拒发）；参考模式是否写了 `--aspect 9:16`；关键帧是否用 `normalise_keyframes.py` 按竖版统一过 | 3.10 |
| 产品形状、朝向、接口和实物对不上 | 外观和功能事实文件有没有请产品方确认；3D 场景有没有从每个真实机位检查过 | 0.2、0.3、2.6 |
| 改过的错误又回来了，或改了参数重渲结果没变 | 旧说法的残留词；有没有手改过的生成文件被重跑覆盖；渲染器实际读哪个文件、缓存有没有跳过 | 0.4、5.9、2.10 |
| 闸门大量判失败 | 闸门校准过没有；是不是图像模型合理的重新诠释；是不是只差缩放（可配准）；先截图核实 | 5.6、5.7、3.8 |
| 提交失败，或参考素材读不到 | 临时链接是否过期；文件是否超过上传上限；任务号有没有记下 | 4.10 |

## 剪辑与字幕

| 现象 | 先查什么 | 规则 |
|---|---|---|
| 镜头之间生硬、跳 | 衔接点事先设计过没有；前后运动是否连续；有没有把静止画面叠进运动镜头 | 6.2、6.3 |
| 字幕盖住人物或产品 | 位置是不是只在灰色底图上定的；竖版是否在平台安全区内 | 7.2、7.11 |
| 竖版的字幕或片尾小字被平台按钮、文案挡住 | `edit/edl.json` 有没有写 `"size": [1080, 1920]`（没写会按横版排）；字幕样式有没有用 `"preset": "feed_safe"`；`--dry` 的 SAFE BOX 报告 | 7.11 |
| 剪辑器报字幕间隔或阅读时间不够 | 片段长度、阅读时间规则、标注条数 × 间隔；放慢或加停留，不改规则 | 7.3、7.4 |
| 〔广告〕观众很快划走，前几秒留不住人 | 前 2–3 秒有没有钩子；第一帧是不是黑场或 logo 淡入；品牌是否早露出 | 1.9、1.10、10.9 |
| 〔广告〕静音播放时看不懂 | 关键信息是不是只在配音里；上屏文字是否足够 | 1.12 |
| 〔广告〕剪短版不像一支完整的片，或各版本的 logo、颜色、字体对不上 | 每个剪短版有没有自己的钩子、卖点画面和片尾卡；是否都从主 EDL 和同一份品牌设定文件派生 | 1.13、10.7、7.10 |

## 声音

| 现象 | 先查什么 | 规则 |
|---|---|---|
| 产品声音或提示音被音乐盖住 | 各窗口"音效减音乐"的实测 dB 差，以及闪避有多深；闪避量是不是按"相对于没压过的音乐分轨"的总量算的 | 9.8 |
| 提示音按整段测已经够响，听起来仍被盖住 | 是不是只看了整段平均；按每个提示音约 60 ms 逐个测 | 9.8 |
| 音乐转场突兀 | 接点是否落在共同和弦上，而不是静音处 | 9.6 |
| 提示音刺耳，或有一层噪声一直在响 | 提示音的音色和音高是否跟配乐同调；底噪是否随场景结束 | 9.5、9.7 |
| AI 配音听起来假，或配音念不完、挤掉片尾卡 | 有没有做过响度对齐的盲听 A/B；配音字数是否按时长做过预算 | 9.11、9.13 |

## 合规、交付与流程

| 现象 | 先查什么 | 规则 |
|---|---|---|
| 文案过了词表闸门，审核仍说有问题 | 是否暗示了产品没有的功能；广告里有没有证言、比较、价格这类说法 | 8.2、8.7、8.9 |
| 文件发不到手机 | 文件是否超过聊天工具的附件上限；有没有另出分享版 | 10.1 |
| 后台任务一夜没进展 | 电脑是否睡眠、是否断网；工作流能不能从磁盘续跑 | 11.6、11.7 |
| 账单比预期高，或突然欠费，新任务被拒 | 套餐真实能抵扣多少；这一批提交前有没有看余额；自己的生成日志 | 11.1、11.2 |
| 打印中文时崩溃、路径找不到、找不到 ffmpeg | 是否设了 UTF-8 输出、路径是否用 pathlib、ffmpeg 是否从 imageio-ffmpeg 取 | 11.13 |

## 表里没有的现象，按这个顺序查

1. **先看原片，不看成片**：问题是生成出来的，还是剪辑、字幕、混音加上去的？
2. **再查输入**：事实文件、底图、关键帧、参考包、提示词，哪一份把错误带了进来？模型会照抄你给它的一切，没写到的地方它会自己补。
3. **一次只改一个变量**，保留旧版本，用最便宜的方式验证（低清草稿、单张静帧、单独一段音频）。
4. **修好之后**，按同样格式在这里加一行，并在 `rulebook.md` 对应组末尾补一条规则。
