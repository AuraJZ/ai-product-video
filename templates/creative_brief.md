# 创意简报：<片名>

> 一页纸说清：这支片为什么做、给谁看、在哪里播、说什么、不说什么。
> 复制成项目的 `brief/creative_brief.md`，第一天和用户一起填（问法见 `../references/01-intake.md` 第 11 节）；之后每次大改方向，都回来对照并更新"变更记录"。
> 右栏的示例是一支**虚构的 20 秒竖屏信息流广告**（智能保温杯），开工时删掉。

| 项 | 填写 | 说明 / 示例 |
|---|---|---|
| 片名（工作名） | | 示例：X1 保温杯 · 信息流 20 秒 |
| 视频类型 | | 产品讲解片 / 投资人演示片 / 广告（信息流、开屏、贴片）/ 发布会短片 / 电商主图视频 / 社交平台短视频。规格见 `../references/02-formats.md` |
| 目标 | | 看完要观众做的一件事，用一个动词：投资、下单、点进详情页、记住名字。示例：点进详情页 |
| 观众 | | 内部（投资人、合作方）还是公开？公开版本不放爆炸图、透视图和内部部件标注。他们是谁、已经知道什么、最在意什么。示例：25–35 岁上班族；用过保温杯，没听说过"会提醒喝水的杯子"；在意好不好看、麻不麻烦 |
| 播放平台与场景 | | 在哪里、什么状态下看。示例：手机竖屏信息流，默认静音，前 3 秒决定划不划走 |
| 时长 | | 示例：20 秒，另出一条 6 秒的短版 |
| 画幅与分辨率 | | 示例：主画幅 9:16（1080×1920），另出 1:1。产品和字幕放在两个画幅共有的中间区域 |
| 主信息（一句话） | | 观众只记住一句话的话，是哪一句。示例：「到点了，它会提醒你喝水」 |
| 支撑点（最多 3 个） | | 示例：① 看一眼就知道水温 ② 到点提醒 ③ 喝了多少，手机上有记录 |
| 语气与风格 | | 3 个形容词，加一部参考片。示例：干净、明亮、有生活感；参考片见 `benchmark.md` |
| 必须出现 | | 示例：产品正面和字样；水温显示亮起；App 画面（真实截图） |
| 不能出现 | | 示例：竞品、价格、内部结构、人物正脸、还没做出来的功能 |
| 允许的说法 | | 只用 `product_facts.md` 里"已确认"且"可公开"的功能。示例：显示水温、到点提醒、记录饮水量 |
| 不允许的说法 | | 功效、医疗、最高级、绝对化、没有依据的数字。示例：不写"更健康""最好用""保温 12 小时" |
| 字幕 / 配音 / 音乐 | | 示例：信息全部由字幕承担；不配音；音乐轻快，要可商用的授权 |
| 产品自带的声音 | | 有没有提示音、开机音的原始文件。示例：有一段提醒音（WAV） |
| 人物 | | 要不要出现人、出现到什么程度。示例：只出现手和侧后方身影，不露正脸 |
| 语言版本 | | 示例：先做中文，英文版之后由同一份文案文件生成 |
| 交付物 | | 列文件清单。示例：9:16 母版、1:1 母版、30 MB 以内的分享版、无字幕版、封面图 |
| 截止日期与中间节点 | | 示例：11-05 交投放团队；11-01 先看粗剪 |
| 预算上限 | | 生成费用上限，花到多少先问。详见 `budget.md` |
| 谁拍板 | | 一个人，写职位即可。示例：创始人 |
| 参考片 | | 文件或链接，并写清"学它什么"（质感）和"不学什么"（结构、节奏） |
