# 素材来源与许可：<片名>

> **怎么用**
> - 复制成项目的 `brief/licenses.md`。所有外部素材（音乐、音效、字体、图片、视频素材）、产品方提供的素材、自制素材、模型生成的画面和声音，都在这里各占一行，**下载或生成当天就记**。
> - 许可证页面存一份截图或 PDF，放进 `brief/licenses/`，在"许可证存档"一栏写文件名。
> - 查不到许可的写"未核实"，不进公开版本。
> - 片尾署名照第 2 节逐字复制，不要另写一份。
> - 规则说明见 `../references/09-compliance.md` 第 5 节；音乐和音效的选用见 `../references/07-sound.md` 第 2、6 节。下面的示例行是虚构的，开工时替换。

## 2. 片尾署名文本

逐字复制到片尾卡的小字和视频简介里；改了这里，同步改 `edit/captions.json` 的片尾卡。

```text
Music: "<曲名>" by <作者>, licensed under CC BY 4.0 (edited)
```

## 4. 检查

- [ ] 每个外部素材都有来源、作者、许可证和存档
- [ ] 没有 NC（非商业）或 ND（禁止演绎）素材进入商用版本
- [ ] 平台曲库的音乐没有搬到别的平台
- [ ] CC BY 署名完整（标题、作者、来源、许可证，剪辑过的注明 edited），和第 2 节一致
- [ ] 每款字体都确认了商用授权
- [ ] 生成用的服务和套餐允许商用（广告投放时允许广告用途）
- [ ] "未核实"的素材没有进入公开版本
