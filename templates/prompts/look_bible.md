# 统一设定（look bible）模板

每张关键帧的提示词都以下面这一段开头，**全片一字不改**（用脚本核对哈希值）。把 `〈占位〉` 换成你的产品和场景，删掉用不上的条目后重新编号。为什么这么写，见 `references/04-keyframes.md` 第 2 节。

填好后把代码块里的全文存成项目的 **`packs/look_bible.txt`**：这是统一设定的唯一来源，每个出图包的 `prompt.txt` 都从它原样拼接。

规则：

- 只写全片不变的东西。某一张要例外时，不改这一段，在本张补充里写"本张例外（改写统一设定第 N 条）"。
- 外观数据从已确认的产品事实单复制（项目的 `brief/product_facts.md`），不要凭印象写。
- 先用它画母版（产品母版、场景母版、需要时的人物设定图），每张过检查点、用户认可后再画镜头关键帧（`references/04-keyframes.md` 第 3、5 节）。
- 只有一件产品时删掉第 4、5 条并重新编号；没有连接线时删掉第 4 条，以及第 3、5 条里关于接口和线的内容。第 2、7、9 条一般不动。
- 只写看得见的外观，不写内部结构和工作原理。
- 一种语言写到底。

---

## 模板（从下一行的代码块开始复制）

```text
请画一张〈横版 16:9 / 竖版 9:16〉的写实照片（宽:高 = 〈16:9 / 9:16〉）。

统一设定（每一张都相同）：
1. 画面质感：这是〈品牌〉〈品类〉〈广告片 / 产品片〉里的一帧，要像用电影摄影机和定焦镜头真实拍摄的高端〈场景类型，如 家居 / 影棚 / 户外〉广告剧照。透视、焦段、景深和对焦位置以图1为准；高光柔和不过曝，暗部通透有细节，〈色彩倾向，如 色彩克制、低饱和 / 暖调、逆光〉，带轻微胶片颗粒；〈主要材质，如 布料、木纹、金属和玻璃〉都真实细腻。不要 CG 渲染感、塑料感或插画感。
2. 图1是布景底图：构图、机位、透视，画面里每样东西的位置、轮廓、大小比例，以及连接线的走向，都和图1完全一致，不移动、不增减、不变形；只把图1的灰模材质和光照画成真实拍摄的样子。其他上传的图只用来参考产品和场景长什么样，不改变图1的构图和机位。
3. 〈产品A名称〉：〈尺寸，或"和〈常见参照物〉一样大"〉，〈形状〉，〈颜色与材质〉，〈表面细节：接缝、纹理、边〉，〈接口 / 按键的位置〉。〈材质〉只反射环境光，本身从不发光，没有灯带，没有发光的边。
4. 〈连接件，没有就删掉这一条〉：〈宽度、颜色、材质〉，从〈接口〉引出，以柔和的弧线落到下面的表面上，之后一直平贴着走，不悬空、不打急弯、不穿进任何物体；从〈产品B〉〈哪一面〉接入，插头被机身挡住看不见。线的具体走向完全照图1。
5. 〈产品B名称，没有就删掉〉：〈尺寸参照〉，〈外壳颜色与质感〉，〈正面元素〉，〈字样内容与位置〉。〈指示灯〉亮起时只是〈形状，如 一条细而均匀的线〉，光只落在〈哪些表面〉上，空气中没有光晕和光束。
6. 〈场景〉（〈如果片中同一地点有几个时段：这些时段是同一个空间〉；左右按〈参照方向，如 面向窗户、窗在右手边〉来说）：〈家具〉；〈墙面、地面〉；〈窗和窗帘〉；〈灯具〉；〈植物、装饰〉。只画图1里看得到的部分，不要因为这段描述而添加图1里没有的东西。
7. 人物：任何一张图都不出现人脸，画面里不能有眼睛、鼻子或嘴。
8. 文字：除〈产品上本来就有的字样〉外，画面里没有任何文字、标志、水印、字幕、边框或标签。
9. 画幅：〈横版 16:9 / 竖版 9:16〉（宽:高 = 〈16:9 / 9:16〉），一张完整的照片，不拼图，不留白边。
```

---

## 第 1 条的几种写法

按片子类型选一种，全片只用一种：

| 类型 | 第 1 条里的风格描述 |
|---|---|
| 家居产品解说片 | 高端家居广告剧照；色彩克制、低饱和；柔和的自然光和室内光 |
| 影棚产品片 | 浅灰无缝背景的影棚；大面积柔光，产品边缘有细的轮廓光；背景干净无杂物 |
| 户外 / 运动产品广告 | 自然光实拍；〈时段，如 傍晚逆光〉；空气通透，有真实的景深和动态 |
| 品牌广告 | 写进品牌的主色调、光线风格和调色方向，比如"暖色调、浅景深、柔和的侧逆光" |

## 没有 3D 底图时第 2 条的写法

```text
2. 图1是构图底图（〈2D 合成图 / 实拍代理照片〉）：构图、机位、透视、产品在画面里的位置和大小都和图1一致；图1里〈代理物，如 纸盒〉的位置就是〈产品〉的位置。产品的外观以图2（产品参考表）为准，每个接口、字样、按键的位置都照图2，不增加、不省略。
```

用这一条时，出图包的固定纠正话换成无 3D 的那一句（"图1里代理物的位置就是产品；产品外观照图2"，见 `keyframe_pack.md` 开头），因为图1 里没有灰模可"画成真实照片"。镜头表里这些关键帧的 `source` 写 `image_on_proxy`。

## 补拍镜头（没有底图）时第 2 条的改法

不改统一设定本身，在本张补充里写一行例外（完整示例见 `keyframe_pack.md` 的"补拍镜头"）：

```text
本张例外（只对这一张，改写统一设定第 2 条）：这张没有布景底图。图1 是已经批准的关键帧〈id〉：产品的外观、位置和比例，房间的光线和色调都照它；本张只改〈机位 / 景别 / 时刻 / 状态的变化〉。
```

## "本张例外"的写法

```text
本张例外（只对这一张，改写统一设定第〈N〉条）：〈为什么例外〉。〈具体改成什么〉。
```

例：

```text
本张例外（只对这一张，改写统一设定第 5 条）：这一刻灯光照到了墙上。允许墙面上有一片柔和的暖色光，从〈产品〉方向扩开；产品本体仍然只有细线状的指示灯，空气中仍然没有光束。
```
