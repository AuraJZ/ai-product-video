# AI 过渡镜头（bridge）提示词模板（约 4 秒，首尾帧模式）
# 这几行以 # 开头的说明不要复制进提示词。用法见 references/05-video-gen.md 第 12 节和 references/06-edit-type.md 第 3 节。
# - 只用在：同一空间、同一时刻、画面里没有脸的两个镜头之间。
# - 首帧 = 上一镜实际出点的那一帧；尾帧 = 下一镜实际入点的那一帧。都从原片逐帧导出，不重画。
# - 运动节奏要和前后镜头匹配：前后都在动，就写全程运动、在第 4 秒到位，不写"减速再停住"。
#   前一镜结束时静止、后一镜开始时静止，才写"由静止起步"和"减速到停稳"。
# - 剪辑时入点约 0.04 秒（跳过和上一镜重复的第 0 帧），出点按实测运动量定；EDL 里给它设后备叠化。
# - 不用【】()<>{} 等符号；不写改变任务类型的词。
# ---- 从下一行开始复制 ----
首帧就是给定的首帧图片，尾帧就是给定的尾帧图片，镜头从首帧连续运动到尾帧，中间不切镜。〈场景一句话：空间、时刻、产品此刻的状态〉。
0-1秒：镜头〈保持上一镜的运动方向，平稳地向〈方向〉运动 / 由静止起步，向〈方向〉运动〉。结束时〈状态，如 〈物体〉开始进入画面〉。
1-2秒：〈运动保持匀速〉；〈画面里逐渐出现什么，以固定物为参照〉。结束时〈状态〉。
2-3秒：〈运动保持平稳〉，构图接近尾帧。结束时〈镜头仍在缓慢运动 / 镜头开始减速〉。
3-4秒：〈镜头以很慢的速度继续运动，不停下，平稳地到达尾帧构图 / 镜头减速并停稳〉。结束时画面与尾帧一致。
〈产品〉、〈家具〉全程不移动、不变形，只有镜头在动。〈效果保持什么状态，如 指示灯亮度不变〉。〈材质〉是哑光的，本身不发光。画面里只有首帧和尾帧已有的物体，没有人，除〈产品自身字样〉外，不显示字幕、文字或标牌。
