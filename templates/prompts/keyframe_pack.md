# 出图包模板

两部分：

- **A. 一轮的说明文件**（比如 `本轮出图_〈N〉张.md`）：交给用户的唯一文件，按顺序列出这一轮要画的所有图。
- **B. 每张图的文件夹**：上传图按编号放好，外加 `prompt.txt` 和 `README.md`。

规则说明见 `references/04-keyframes.md` 第 3–5 节。`〈占位〉` 换成实际内容，路径写完整，用户照着点就行。

三条硬规矩：

- **母版轮在最前面**：第一轮只画母版（产品母版、场景母版、需要时的人物设定图），每张过检查点、用户认可后，才出镜头关键帧的出图包。之后每张都把母版当图2、图3……上传。
- **每张图的提示词完整地放在同一个代码块里**：统一设定和本张补充行（本张例外、本张上传、画面、光线、效果状态、人物、特别注意）全在同一个代码块里，块外不放任何要粘贴的文字。把统一设定单独关成一个块、补充行落在块外，用户就只会复制到半条提示词。`prompt.txt` 和代码块里的内容逐字相同。
- **先问用户用什么工具出图**：只有订阅、在网页或 App 里手动画，就用这份出图包；有图像 API，就由脚本按同样的上传顺序和提示词批量出图，出图包只留作记录（`references/04-keyframes.md` 第 10 节）。

**固定纠正话**按路线二选一，一轮里只用一句：

- 有 3D 底图（`image_on_plate`）：构图、产品的位置和大小必须和图1完全一致，只把灰模画成真实照片；其他要求不变，请重画一张。
- 无 3D 路线（`image_on_proxy`，图1 是 2D 合成底图或实拍代理照片，统一设定第 2 条用 `look_bible.md` 的无 3D 写法）：构图、机位和产品的位置大小必须和图1完全一致，图1里代理物的位置就是产品；产品外观照图2。其他要求不变，请重画一张。

## A. 一轮的说明文件

````markdown
# 本轮出图：〈这一轮的目的，比如 新增镜头 S12 和 S13〉（〈N〉张）

用途：〈一两句话：这些图在片里做什么，为什么要画〉

**每张都在〈图像模型名称〉里新开一个对话**：按顺序上传图片 → 整段复制提示词，作为一条消息发出 → 按"画完检查"看 → 通过就下载原图（不是截图），存成指定的文件名。

顺序和依赖：先画第 1 张；第 2 张要上传第 1 张的结果。〈其他依赖〉

检查点：画完第〈2〉张先停下，把图发给 Claude 看，通过后再继续。

不合格时：只回复一次下面这句话；还不行就新开一个对话重画，不要在同一个对话里反复改。

> 〈固定纠正话：有 3D 底图用第一句，无 3D 路线用第二句，见本模板开头〉

---

## 第 1 张：〈镜头〉-K〈秒数〉

**用途**：〈一句话〉

**文件夹**：`〈项目路径〉/packs/〈序号〉_〈镜头〉-K〈秒数〉/`

**按顺序上传**：
1. `01_plate.png` —— 布景底图（构图照它）
2. `02_〈产品母版〉.png` —— 产品外观照它
3. `03_〈场景母版〉.png` —— 场景外观照它
4. 〈同镜头已画好的前一帧，没有就删掉〉

**提示词**（整段复制，作为一条消息发出；代码块里就是完整的提示词）：

```text
〈统一设定：packs/look_bible.txt 的全文，一字不改〉

本张例外（只对这一张，改写统一设定第〈N〉条）：〈没有就删掉这一行〉
本张上传：图1 = 布景底图：构图、机位、每样东西的位置和大小照它；图2 = 〈产品〉母版：外观、颜色、材质照它，不照它的背景和角度；图3 = 〈场景〉母版：〈照它的什么〉，不照它的构图。
本张画面：〈时间、景别、主体、背景〉
光线：〈光从哪来、多强、什么颜色、哪里暗〉
效果状态：〈这一刻效果处在什么状态，按摄影机看得到的样子写；它不是什么〉
人物：〈画面中没有人 / 只露背影或后脑，看不到脸 / 头在画外〉
特别注意：〈最容易画错的 1–2 点〉
```

**存成**：`〈项目路径〉/keyframes/raw/〈镜头〉-K〈秒数〉.png`

**画完检查**：
1. 构图、机位、景深和图1一样：〈主体〉在同一位置、同样大小。
2. 光线：〈应有的光〉；没有〈不该有的光〉。
3. 效果：〈正确状态〉；没有〈常见错误，如 光晕、灯带、颜色偏粉〉。
4. 没有人脸，没有多余的文字，〈产品字样〉清楚、没有镜像。
````

## B. 每张图的文件夹

```
packs/〈序号〉_〈镜头〉-K〈秒数〉/
  01_plate.png
  02_〈产品母版〉.png
  03_〈场景母版〉.png
  prompt.txt        # look bible + this image's lines; the look bible block is byte-identical across packs
  README.md         # save-as name, checks, the one correction sentence
```

`README.md`：

```markdown
# 〈镜头〉-K〈秒数〉

1. 在〈图像模型名称〉里新开一个对话。
2. 按文件名顺序上传 01、02、03……
3. 打开 prompt.txt，全选复制，作为一条消息发出。
4. 下载原图，存成：〈完整路径〉/keyframes/raw/〈镜头〉-K〈秒数〉.png
5. 画完检查：
   - 〈检查 1〉
   - 〈检查 2〉
   - 〈检查 3〉
6. 不合格时只回复一次："〈本轮的固定纠正话〉" 还不行就新开对话重画。
```

生成这些文件夹的是**项目自己写的脚本**（例如 `work/make_packs.py`，本 skill 不附带），它要做到：

- 从关键帧清单（`keyframes/keyframes.json`，模板 `templates/keyframes.example.json`）读出每张图的上传、存成名和依赖；
- 把 `packs/look_bible.txt` 原样拼进每个 `prompt.txt`，并检查所有出图包里的这一段哈希值相同；
- 一张图依赖另一张时，在说明文件里写明先后，并在依赖的图还没画好时提示。
