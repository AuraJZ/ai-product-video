# 手动视频包模板（网页或 App 会员，没有 API）

用户的视频模型账号只有网页或 App 会员、没有 API 密钥时，视频由用户手动生成。Claude 照这份模板交一个**手动视频包**：每个镜头一个文件夹，上传顺序、设置、提示词、下载后的文件名都写死，用户照着点就行。规则见 `references/05-video-gen.md` 第 7、14 节和 `references/01-intake.md` 第 8 节。

开工前先确认三件事（写进 `brief/decisions.md`）：

1. **商用条款**：消费级会员的条款不一定允许广告用途。投放类广告先确认条款，或换企业 API（`references/09-compliance.md` 第 5.5 节）。
2. **有没有"草稿原样升级"**：多数网页端没有。没有时，高清版就是重新生成：草稿只用来选构图和提示词，批准后按同样的输入再出一条高清，高清版重新逐帧审、剪辑点重新定。预算按重抽算（`budget.md`）。
3. **画幅**：网页端常常有单独的画幅选项，不一定跟随首帧。竖版片每一次都选 9:16。

`〈占位〉` 换成实际内容，路径写完整。

---

## A. 一轮的说明文件（例如 `packs/video_round_〈N〉.md`）

````markdown
# 本轮视频：〈这一轮的目的〉（〈N〉条）

**每条都按下面的顺序操作**：新建一个生成任务 → 选模式和设置 → 按编号上传图片 → 整段复制提示词 → 生成 → 下载原文件（不是录屏），按"存成"改名放好 → 在 `gen/video_log.jsonl` 末尾加一行（格式见下）。

设置（每条都一样，除非这条另写）：
- 模式：〈首尾帧 / 只给首帧〉
- 画幅：〈9:16〉（**每次都检查**）
- 时长：〈5〉秒
- 清晰度：草稿用最低档；批准后再出高清
- 声音：关（音乐和音效后期另做）
- 其他：〈水印、运动强度等平台选项〉

检查点：第〈1〉条下载后先停下，把文件发给 Claude 看，通过后再继续。

---

## 第 1 条：〈镜头〉

**文件夹**：`〈项目路径〉/packs/video_〈序号〉_〈镜头〉/`

**按顺序上传**：
1. `01_first.png` —— 首帧（`keyframes/norm/〈镜头〉-K00.png` 的副本）
2. `02_last.png` —— 尾帧（`keyframes/norm/〈镜头〉-K〈秒数〉.png` 的副本；只给首帧时删掉这一行）

**提示词**（整段复制，作为一条消息发出；和 `shots/prompts/〈镜头〉.txt` 逐字相同）：

```text
〈逐秒提示词〉
```

**存成**：`〈项目路径〉/gen/〈镜头〉/m-〈日期〉-〈镜头〉-〈第几次〉.mp4`，例如 `gen/S01/m-20261026-S01-1.mp4`

**看完检查**：
1. 画幅是竖的，首帧和尾帧都对上了。
2. 〈这一镜最容易出错的 1–2 点〉
````

## B. 手动生成的账本行

`gen/video_log.jsonl` 每行一条 JSON。手动生成的那一条照下面写（任务号就用文件名里的 `m-…`），`seedance.py log` 会把它算进"已完成"：

```json
{"time": "2026-10-26T15:04:00+08:00", "action": "done", "manual": true, "shot": "S01", "task": "m-20261026-S01-1", "mode": "first_last", "resolution": "480p", "aspect": "9:16", "duration": 5, "inputs": ["keyframes/norm/S01-K00.png", "keyframes/norm/S01-K04.png"], "prompt_source": "shots/prompts/S01.txt", "tool": "<平台和会员档位>", "credits": 10, "files": ["gen/S01/m-20261026-S01-1.mp4"]}
```

- `credits` 记平台扣的积分或次数；能换算成钱时另加 `"cost_cny_list"`。
- 批准后在 `edit/approved_drafts.json` 里直接写文件路径：`"S01": "gen/S01/m-20261026-S01-2.mp4"`。这种账本不交给 `seedance.py upgrade`（它只认 API 任务号）。

## 工具备注（2026-10，使用前核对最新文档）

- 即梦、豆包等消费级 App 和网页端提供首帧 / 首尾帧生成，但没有 API 密钥，`scripts/video_api/seedance.py` 用不上；它们的条款、清晰度档位、有没有草稿升级、积分规则和企业 API（火山方舟、BytePlus ModelArk）不同，按当时的页面核对。
